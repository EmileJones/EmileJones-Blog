在了解了强化学习的 [基本理论](/posts/ai/强化学习理论基础/) 后，可以进一步比较几种基于时序差分学习的动作价值函数方法：Q-Learning、SARSA 和 DQN。

本文中的 $Q(s,a)$ 表示动作价值函数：在状态 $s$ 下采取动作 $a$ 后，未来能够获得的期望累计回报。它不等同于当前这一步的即时奖励。Q-Learning 和 SARSA 通常使用表格存储不同状态-动作组合的价值，DQN 则使用神经网络近似这个函数。

# Q-Learning

Q-Learning 在更新时，并不在意下一时刻实际会做什么动作，而是假设下一时刻一定会选择能带来 **最大** $Q$ **值** 的动作。

其中，$Q$ 代表质量（Quality）。$Q(s,a)$ 表示在状态 $s$ 下采取动作 $a$ 后的期望累计回报。

**算法步骤：**

1.  **初始化**：设置学习率 α、折扣因子 γ、探索率 ϵ，并初始化 Q(s,a) 表。

2.  **循环每一个回合（Episode）**：

    1.  使用策略（如 ϵ-greedy）根据当前的 Q 值表选择动作 a。

    2.  执行动作 $a$，观测回报 $r$ 和转移后的新状态 $s'$。

    3.  更新 Q 值。非终止状态使用下一状态的最大 Q 值作为目标：$Q(s,a)\leftarrow Q(s,a)+\alpha\left[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\right]$。如果 $s'$ 是终止状态，则不再添加折扣后的未来价值，目标值为 $r$。

    4.  更新状态：$s\leftarrow s'$。

    5.  如果 s 是终止状态，则跳出该回合循环。

**优点**：通过异策略（Off-policy）下的最大化算子，Q-Learning 可以使用探索策略收集样本，同时学习贪心的最优策略。在有限状态、有限动作的表格型环境中，如果满足充分探索和合适的学习率等条件，理论上可以收敛到最优动作价值函数。

**缺点**：最大化操作会放大 Q 值估计误差，容易产生 **价值过估计（Overestimation）**。此外，Q-Learning 的更新目标使用理论上的最优动作，而不是实际探索动作，因此在探索代价较高的环境中，可能低估探索风险，训练初期的行为也可能不稳定。

# SARSA

SARSA 的名称来源于其决策序列：$S_t,A_t,R_{t+1},S_{t+1},A_{t+1}$。它在更新当前状态的 Q 值时，使用的是下一时刻 **实际采取** 的动作。

**算法步骤：**

1.  **初始化**：设置学习率 α、折扣因子 γ、探索率 ϵ，并初始化 Q(s,a) 表（通常设为 0 或随机值）。

2.  **循环每一个回合（Episode）**：

    1.  使用策略（如 ϵ-greedy）根据当前的 Q 值表选择动作 a。

    2.  执行动作 $a$，观测回报 $r$ 和转移后的新状态 $s'$。

    3.  使用相同的策略（如 $\epsilon$-greedy）在状态 $s'$ 下选择下一个动作 $a'$。

    4.  更新 Q 值：$Q(s,a)\leftarrow Q(s,a)+\alpha[r+\gamma Q(s',a')-Q(s,a)]$。

    5.  更新状态和动作：$s\leftarrow s', a\leftarrow a'$。

    6.  如果 s 是终止状态，则跳出该回合循环。

**优点**：采用同策略（On-policy）更新机制，能够将当前探索策略下的 **随机风险** 纳入价值评估。在探索代价较高的环境中，它可能学习到比 Q-Learning 更保守的行为。

**缺点**：价值估计依赖当前行为策略；如果探索率保持不变，学习到的策略会包含持续探索带来的风险，可能不是理论上的最短或最优路径。标准 SARSA 通常在线更新，不能像带经验回放的 DQN 那样直接反复采样历史经验，因此样本利用率相对有限。

# Q-Learning 与 SARSA 的核心区别

## 更新目标的差异

Q-Learning 使用下一状态中最大的 Q 值作为更新目标：

$$
r+\gamma\max_{a'}Q(s',a')
$$

它评估的是“如果之后始终选择最优动作，当前动作的价值是多少”。因此，实际执行动作时使用的探索策略不会直接出现在更新目标中。

SARSA 使用下一状态中实际采取的动作对应的 Q 值：

$$
r+\gamma Q(s',a')
$$

其中 $a'$ 是按照当前行为策略实际选择的动作。因此，探索行为及其可能带来的风险会被纳入价值评估。

## 同策略与异策略

Q-Learning 是异策略（Off-policy）方法：它可以使用一个包含随机探索的行为策略收集经验，同时学习理想的贪心策略。

SARSA 是同策略（On-policy）方法：它按照当前实际使用的行为策略进行学习。如果行为策略包含随机探索，更新过程也会评估这种探索行为的影响。

## 悬崖行走示例

考虑一个网格环境：起点和终点位于同一侧，二者之间的下方区域是悬崖。智能体可以沿悬崖边缘行走，以较少的步数到达终点，也可以向上绕行，路线更长但更安全。每走一步获得 $-1$ 的奖励，掉入悬崖获得 $-100$ 的奖励并回到起点。

可以用下面的地图表示这个环境：

```text
上层：·  ·  ·  ·  ·  ·  ·  ·  ·  ·  ·  ·
中层：·  ·  ·  ·  ·  ·  ·  ·  ·  ·  ·  ·
下层：S  C  C  C  C  C  C  C  C  C  C  G

S：起点    G：终点    C：悬崖
```

智能体从 $S$ 出发，需要先向上移动，再向右移动，最后向下移动到达 $G$。沿着中层移动是步数较少但靠近悬崖的路线；沿着上层绕行则步数更多，但探索时不容易掉入悬崖。

假设智能体使用 $\epsilon$-greedy 策略进行探索。在悬崖边缘的状态 $s'$，当前 Q 值估计如下：

```text
向终点方向移动：-1
远离悬崖移动：-2
向悬崖移动：-100
```

如果下一步理论上选择 Q 值最大的动作，Q-Learning 会使用 $-1$ 计算更新目标。它学习的是“后续始终选择最优动作”这一假设下的价值，因此可能选择贴近悬崖的最短路线。

SARSA 使用下一步实际采取的动作。如果智能体因为探索而选择了“向悬崖移动”，更新目标就会包含 $-100$ 的惩罚。这个风险会反向影响前面的状态，使 SARSA 更倾向于选择远离悬崖的路线。

在这个环境中，Q-Learning 可能学习贴近悬崖的最短路线，因为它的更新目标假设后续会选择最优动作；SARSA 则可能学习远离悬崖的安全路线，因为它会考虑探索过程中掉入悬崖的风险。

这个结果并不表示 Q-Learning 一定优于或劣于 SARSA，而是说明两种方法优化的对象不同：前者更关注理想最优策略，后者更关注当前行为策略下的实际回报。SARSA 也并非必然只能得到次优策略；当探索率逐渐衰减时，它也可能逐渐收敛到最优策略。

## 小结

| 特性 | Q-Learning | SARSA | DQN |
| --- | --- | --- | --- |
| 价值表示 | Q 表 | Q 表 | 神经网络 |
| 更新目标 | 下一状态的最大 Q 值 | 下一状态实际动作的 Q 值 | 目标网络给出的下一状态最大 Q 值 |
| 策略类型 | 异策略（Off-policy） | 同策略（On-policy） | 异策略（Off-policy） |
| 状态输入 | 离散状态 | 离散状态 | 数值特征、图像等状态表示 |
| 动作空间 | 通常为离散动作 | 通常为离散动作 | 原生实现要求离散动作 |

# Deep Q-Network(DQN)

DQN (Deep Q-Network) 的核心思想是将神经网络的特征提取能力与 Q-Learning 的决策方法结合。它使用神经网络近似动作价值函数，从而能够处理传统 Q 表难以直接表示的高维状态空间，例如图像。

DQN 的输入是当前状态 $s_t$，可以是数值特征、图像或其他经过预处理的状态表示。网络一次输出该状态下所有离散动作的 Q 值。例如动作集合为“左转、直行、右转”时，输出为：

$$
[Q(s_t,\text{左转}), Q(s_t,\text{直行}), Q(s_t,\text{右转})]
$$

动作选择通常使用 $\epsilon$-greedy 策略：以 $\epsilon$ 的概率随机选择动作，否则选择 Q 值最大的动作。连续动作空间不能直接使用原生 DQN，需要采用适配连续动作的其他方法或进行离散化。

**算法步骤：**

1.  **初始化**：

    - *初始化* **经验回放池** $D$，用于存储历史经验 $(s_t,a_t,r_{t+1},s_{t+1},d_t)$，其中 $d_t$ 表示当前转移是否到达终止状态。

    - *初始化* **当前 Q 网络** $Q(s,a;θ)$，赋予随机权重 $\theta$。

    - *初始化* **目标 Q 网络** $Q(s,a;\theta^-)$，将其参数复制为当前 Q 网络的参数：$\theta^-\leftarrow\theta$。之后每隔一定步数同步一次。

    - 设置学习率$α$、折扣因子$γ$、探索率$ϵ$。

2.  **循环每一个回合（Episode）**：

    1.  **动作选择**：使用 $\epsilon$-greedy 策略。以 $\epsilon$ 的概率随机选动作，以 $1-\epsilon$ 的概率根据 **当前 Q 网络** 选择使 Q 值最大的动作：$a_t=\arg\max_a Q(s_t,a;\theta)$。

    2.  **执行与存储**：在环境中执行动作 $a_t$，观测回报 $r_{t+1}$ 和转移后的新状态 $s_{t+1}$，并将经验 $(s_t,a_t,r_{t+1},s_{t+1},d_t)$ 存入经验回放池。

    3.  **样本采样**：从$D$中随机抽取一个 **小批量（Mini-batch）** 的经验样本。

    4.  **计算目标值**：对于每个样本，使用目标网络计算：$y_j=r_{j+1}+\gamma(1-d_j)\max_{a'}Q(s_{j+1},a';\theta^-)$。当 $d_j=1$ 时，目标值退化为 $y_j=r_{j+1}$。

    5.  **更新网络**：计算目标值 $y_j$ 与当前网络对实际动作的输出 $Q(s_j,a_j;\theta)$ 之间的均方误差（Loss），通过梯度下降更新 $\theta$。

    6.  **同步网络**：每隔$C$步，将当前网络的参数同步给目标网络： $\theta^- \leftarrow \theta$。

    7.  **迭代**：更新状态$s_t \leftarrow s_{t+1}$，直到回合结束。

**优点：**

- **处理高维状态**：能够使用神经网络从图像等高维状态中提取特征，并在相似状态之间进行一定程度的泛化。音频等其他感知数据通常也需要经过适当的预处理或特征表示。

- **训练稳定性更好**：**经验回放** 通过随机采样降低连续交互样本之间的相关性；**目标网络** 在一段时间内固定 TD 目标，减少当前网络参数快速变化造成的更新震荡。这些机制可以改善训练稳定性，但不能保证所有环境都稳定收敛。

- **样本利用率较高**：属于离策略（Off-policy）方法，可以将历史经验保存在回放池中并多次采样。标准 SARSA 通常在线更新，而 DQN 的经验回放机制允许同一条转移在不同训练步骤中被重复使用。

**缺点：**

- **仅限离散动作**：原生 DQN 无法直接处理连续动作空间（如控制赛车转弯的精确角度）。基于 Q 表的 Q-Learning 和 SARSA 通常也要求预先定义有限的离散动作集合。

- **Q 值过估计**：目标值中的 $\max$ 操作可能放大 Q 值估计误差，使某些动作的价值被高估。Double DQN 通过将动作选择与动作评价分离来缓解这一问题。

- **超参数敏感且不保证全局最优**：网络结构、学习率、探索率、回放池大小以及目标网络的更新频率都会影响训练结果。与表格型 Q-Learning 的理论收敛结论不同，DQN 使用非线性函数近似时通常不保证收敛到全局最优策略。
