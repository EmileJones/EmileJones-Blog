强化学习要解决的问题可以简单概括为：智能体不断和环境交互，在每个状态下选择动作，并通过奖励判断自己的行为是否正确。

这一过程中有三个核心问题：

1. 如何描述环境和智能体之间的交互？
2. 如何衡量一个状态，或者一个动作的好坏？
3. 在不知道答案的情况下，如何逐渐估计出这些价值？

本文会按照这条思路，依次介绍 MDP、价值函数、贝尔曼方程，以及 Monte Carlo、Dynamic Programming 和 TD Learning 三种价值估计方法。

# 马尔可夫决策过程（Markov Decision Process, MDP）

## 马尔可夫性（Markov Property）

马尔可夫性是指：**未来仅取决于现在，而与过去无关。**

数学表达式为：

$$
\mathbb{P}(S_{t+1} | S_t, A_t, S_{t-1}, A_{t-1}, \dots)
= \mathbb{P}(S_{t+1} | S_t, A_t)
$$

也就是说，只要当前状态 $S_t$ 已经包含了做出决策所需要的全部信息，我们就不需要再保存完整的历史轨迹。

## 从 MRP 到 MDP

在正式介绍 MDP 之前，可以先看一个更简单的模型：马尔可夫奖励过程（Markov Reward Process, MRP）。

MRP 只有状态、状态转移和奖励，没有动作选择。它通常由四元组表示：

$$\langle S, P, R, \gamma \rangle$$

- $S$（State space）：状态集合。
- $P$（Transition probability）：状态之间的转移概率。
- $R$（Reward function）：在状态转移过程中获得的奖励。
- $\gamma$（Discount factor）：折扣因子，$\gamma \in [0,1]$。

### MRP 和 MDP 的关键区别：动作

MRP 中虽然也可能存在随机状态转移，但系统只记录：

$$P(s'|s)$$

它表示从状态 $s$ 出发，可能转移到哪些下一状态，以及每种结果出现的概率。

但是，MRP 并不关心这些转移是由什么动作导致的。它更像是在描述：

> 按照当前固定的行为方式，系统接下来会如何变化？

MDP 则进一步区分了智能体采取的动作：

$$P(s'|s,a)$$

这使得 MDP 可以表达两种可能性：

1. 同一个动作可能导致不同的结果；
2. 不同动作可能导致不同的结果分布。

例如，在网络路由中，当前位于节点 $S_1$ 时，可以选择两种转发方式：

```text
动作 A1：尝试转发到 S2
动作 A2：尝试转发到 S3
```

由于网络存在拥堵和丢包，即使选择了动作 $A1$，也不一定真的到达 $S_2$：

```text
P(S2|S1,A1)=0.8
P(S3|S1,A1)=0.2
```

而选择动作 $A2$ 后，结果可能是：

```text
P(S2|S1,A2)=0.3
P(S4|S1,A2)=0.7
```

因此：

```text
动作：智能体主动选择做什么
状态转移：环境实际发生了什么
```

如果一个 MDP 中的策略已经固定，那么不同动作会按照策略概率被混合起来：

$$
P_\pi(s'|s)=\sum_a \pi(a|s)P(s'|s,a)
$$

此时，MDP 就可以被简化成一个 MRP。

但这种简化也会丢失动作信息。我们只能知道在当前策略下，状态会如何转移，却无法继续回答：

> 如果换一个动作，结果会不会更好？

所以，MRP 适合评估一套固定行为方式，MDP 则适合研究智能体应该如何选择动作。

MDP 在 MRP 的基础上增加了动作和策略，因此通常由五元组表示：

$$\langle S, A, P, R, \gamma \rangle$$

- $S$（State space）：状态集合。
- $A$（Action space）：动作集合。
- $P$（Transition probability）：采取动作后转移到下一个状态的概率：

  $$P(s' | s, a) = \mathbb{P}(S_{t+1}=s' | S_t=s, A_t=a)$$

- $R$（Reward function）：在状态 $s$ 下采取动作 $a$ 后获得的即时奖励。为了简化表示，通常写成：

  $$R(s,a,s') = \mathbb{E}[R_{t+1} | S_t=s,A_t=a,S_{t+1}=s']$$

- $\gamma$（Discount factor）：折扣因子，用来平衡即时奖励和未来奖励的重要程度。

如果 $\gamma \approx 0$，智能体会变得比较“近视”，主要关注眼前的奖励；如果 $\gamma \approx 1$，智能体会更加重视长期收益。

## 策略（Policy，$\pi$）

策略是智能体的“行为指南”，表示在某个状态下应该选择什么动作。

随机策略可以表示为：

$$\pi(a|s)=\mathbb{P}(A_t=a|S_t=s)$$

它表示在状态 $s$ 下选择动作 $a$ 的概率。

如果每个状态都只对应一个确定的动作，就是确定性策略；如果一个状态可能对应多个动作，就是随机性策略。

# 回报与价值函数

## 回报（Return，$G_t$）

智能体在某个时刻获得的奖励，通常不只看眼前这一步，还要考虑后续可能获得的奖励。因此，我们使用回报来描述从当前时刻开始，未来所有折扣奖励的总和：

$$G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$

例如，假设未来连续获得三个奖励 $-1$，折扣因子为 $0.9$，那么当前时刻看到的回报为：

$$G_t=-1+0.9\times(-1)+0.9^2\times(-1)$$

## 状态价值函数（State Value Function，$V(s)$）

状态价值函数用于衡量一个状态的“好坏”。它表示从状态 $s$ 出发，按照策略 $\pi$ 行动时，未来回报的期望值：

$$V_\pi(s)=\mathbb{E}_\pi[G_t|S_t=s]$$

这个公式是价值函数的定义，并不是某一种具体的计算算法。

如果我们直接根据这个定义计算，就需要从状态 $s$ 出发模拟很多条完整轨迹，直到任务结束，然后对得到的回报求平均。这就是蒙特卡洛方法的基本思想。

## 动作价值函数（Action Value Function，$Q(s,a)$）

状态价值函数只回答“这个状态好不好”，而动作价值函数进一步回答：**在这个状态下采取某个动作好不好？**

也就是说，状态价值函数评价的是“处于这个状态时整体表现如何”，而动作价值函数保留了动作信息，可以进一步比较同一个状态下不同动作的好坏。

它的定义为：

$$Q_\pi(s,a)=\mathbb{E}_\pi[G_t|S_t=s,A_t=a]$$

后续的 Q-Learning、SARSA 和 DQN，主要就是围绕动作价值函数展开的。本文先重点讨论状态价值函数，下一篇再详细介绍这些算法。

# 贝尔曼方程（Bellman Equation）

## 为什么需要贝尔曼方程

直接根据回报定义计算价值，需要一直看到任务结束。如果状态很多，可能的路径数量会迅速增加；如果环境允许无限循环，也不能简单地等待一条轨迹自然结束。

贝尔曼方程提供了另一种思路：

> 当前状态的价值 = 当前一步的奖励 + 下一状态价值的折扣期望

它把一个需要“看透未来”的问题，转化成了只需要看下一步的递归问题。

## 贝尔曼期望方程

对于一个已经确定的策略 $\pi$，状态价值函数满足：

$$
V_\pi(s)=\sum_{a\in A}\pi(a|s)\sum_{s'\in S}P(s'|s,a)
\left[R(s,a,s')+\gamma V_\pi(s')\right]
$$

这个公式包含两层期望：

1. 根据策略 $\pi$，计算选择不同动作的概率；
2. 根据环境的转移概率 $P$，计算到达不同下一状态的概率。

因此，这个公式描述的是**策略评估**：给定一个策略，计算它在每个状态下的价值。

## 贝尔曼最优方程

如果我们不想评估一个固定策略，而是希望直接找到最优策略，就要选择价值最大的动作：

$$
V^*(s)=\max_{a\in A}\sum_{s'\in S}P(s'|s,a)
\left[R(s,a,s')+\gamma V^*(s')\right]
$$

这个公式就是贝尔曼最优方程。Value Iteration（价值迭代）会不断使用这个方程更新价值，直到价值函数逐渐收敛。

需要注意：贝尔曼方程是一种价值递归关系，Value Iteration 则是利用这个关系进行计算的具体算法，两者不是同一个概念。

# 三种价值估计方法

贝尔曼方程告诉了我们价值之间的关系，但实际计算时，我们掌握的信息可能不同。根据是否知道环境模型、是否能够观察完整回合，可以得到三种常见方法。

## 蒙特卡洛（Monte Carlo）

蒙特卡洛方法不需要知道环境的转移概率，也不需要知道奖励函数。它只需要不断和环境交互，收集完整的轨迹。

例如，从状态 $S_1$ 出发，一次完整轨迹得到的奖励为：

$$S_1\rightarrow S_2\rightarrow G$$

对应的回报为：

$$G_t=R_{t+1}+\gamma R_{t+2}$$

经过很多次采样后，可以使用这些回报的平均值估计 $V(S_1)$。

它的优点是思想简单，不需要环境模型；缺点是必须等到一个回合结束后才能更新，而且完整回报的随机性比较大。

## 动态规划（Dynamic Programming）

动态规划需要知道环境的模型。这里的“知道环境”并不是只知道一条已经发生过的轨迹，而是至少要知道每个状态和动作组合可能产生什么结果：

- 转移概率 $P(s'|s,a)$：在状态 $s$ 下采取动作 $a$ 后，可能到达哪些下一状态，以及到达每个状态的概率；
- 奖励函数 $R(s,a,s')$：发生这种状态转移时会获得多少奖励，或者奖励的期望是多少。

例如，在状态 $S_1$ 下采取动作 $A_1$，如果我们知道：

```text
P(S2|S1,A1)=0.8，奖励为 -1
P(S3|S1,A1)=0.2，奖励为 -10
```

那么动态规划就可以提前计算这个动作的期望价值，而不需要真的执行很多次动作：

$$
0.8\times[-1+\gamma V(S_2)]
+0.2\times[-10+\gamma V(S_3)]
$$

这就是动态规划和只观察实际结果的方法之间的区别。动态规划需要知道所有可能的结果及其概率；而在现实环境中，我们有时只知道“执行动作后实际发生了什么”，却不知道其他可能结果的概率，也不知道奖励规律。

如果这些信息完全未知，经典的、基于已知模型的动态规划就无法直接使用。此时可以通过大量交互数据先估计环境模型，再使用动态规划；也可以直接使用 Monte Carlo 或 TD Learning 等不依赖完整环境模型的方法。

有了环境模型之后，动态规划就可以按照贝尔曼方程直接计算所有可能的下一状态。

Value Iteration 的基本更新公式为：

$$
V_{k+1}(s)\leftarrow\max_a\sum_{s'}P(s'|s,a)
\left[R(s,a,s')+\gamma V_k(s')\right]
$$

它不需要真的走完一条完整路径，而是把价值从目标状态逐步向前传播。

动态规划的优点是计算结果比较稳定，缺点是必须知道环境模型，并且状态空间过大时，枚举所有状态和动作会非常昂贵。

## 时序差分学习（Temporal-Difference Learning）

TD Learning 结合了蒙特卡洛和动态规划的特点：

- 和蒙特卡洛一样，它不需要知道环境的完整模型；
- 和动态规划一样，它不需要等到回合结束，就可以根据下一状态的估计值进行更新。

TD 方法使用“一步奖励 + 下一状态估计值”作为新的目标：

$$
V(S_t)\leftarrow V(S_t)+\alpha
\left[R_{t+1}+\gamma V(S_{t+1})-V(S_t)\right]
$$

其中，$\alpha$ 是学习率，表示每次更新时相信新信息的程度。

括号中的部分叫作 TD Error：

$$
\delta_t=R_{t+1}+\gamma V(S_{t+1})-V(S_t)
$$

如果 TD Error 为正，说明实际观察到的结果比原来的估计更好；如果 TD Error 为负，说明实际结果比原来的估计更差。

## 三种方法的对比

| 方法 | 是否需要环境模型 | 是否需要等回合结束 | 更新依据 |
| --- | --- | --- | --- |
| Monte Carlo | 否 | 是 | 完整回报 $G_t$ |
| Dynamic Programming | 是 | 否 | 所有可能转移的期望 |
| TD Learning | 否 | 否 | 一步奖励 + 下一状态估计值 |

可以把它们理解成三种不同的“看未来”方式：

- Monte Carlo：真的走完整条路，再回头总结。
- Dynamic Programming：提前知道所有道路和概率，直接计算。
- TD Learning：只走一步，但参考下一站已有的判断。

# 一个统一的例子：网络路由

假设我们正在为一个局部网络设计智能路由算法，目标是让数据包以最低延迟从起始节点 $S_1$ 到达目标节点 $G$。

## 场景建模

- 状态：网络中的节点 $\{S_1,S_2,S_3,S_4,G\}$。
- 动作：选择将数据包转发给哪个邻居节点。
- 奖励：每经过一条链路就产生负的延迟奖励。
  - 普通链路：$R=-1$。
  - 拥堵链路：$R=-10$。
  - 到达目标 $G$：$R=0$，回合结束。
- 环境：网络可能存在链路抖动，因此选择动作后不一定到达预期节点。

这就构成了一个 MDP。我们希望估计每个节点的价值，并最终选择价值最高的动作。

## Monte Carlo：走完之后再总结

假设一次完整路径为：

$$S_1\rightarrow S_2\rightarrow S_4\rightarrow G$$

每条链路的奖励都是 $-1$，那么这次轨迹的回报为：

$$G_t=-1+\gamma(-1)+\gamma^2(-1)$$

如果采样 1000 次，就可以把这 1000 次得到的回报平均起来，作为 $V(S_1)$ 的估计。

这种方式比较直观，但必须等数据包到达 $G$ 后才能知道整条路径的结果。如果路径很长，或者回合中存在环路，就需要额外设置最大步数等终止条件。

## Value Iteration：让价值逐步传播

如果我们知道网络的转移概率和每条链路的奖励，就可以使用动态规划。

初始化时，假设所有节点的价值都是 0：

$$V_0(S_1)=V_0(S_2)=V_0(S_3)=V_0(S_4)=V_0(G)=0$$

假设 $S_4$ 可以直接到达 $G$，链路奖励为 $-1$，那么第一轮更新为：

$$V_1(S_4)=-1+\gamma V_0(G)=-1$$

下一轮，$S_2$ 可以根据 $S_4$ 的新价值更新：

$$V_2(S_2)=-1+\gamma V_1(S_4)$$

价值就像水波一样，从目标节点逐步向外传播。经过多轮更新后，所有节点的价值会逐渐收敛。

## TD Learning：边走边修正

TD 不需要知道整个网络，也不需要等数据包最终到达目标节点。

假设当前估计：

$$V(S_1)=-5,\quad V(S_2)=-5$$

数据包从 $S_1$ 出发，实际到达了 $S_2$，并且这一段链路的奖励为 $-1$。

为了突出更新过程，下面暂时取 $\gamma=1$。

此时，$S_1$ 的新目标值为：

$$R+\gamma V(S_2)=-1+(-5)=-6$$

如果学习率 $\alpha=0.1$，那么：

$$
V(S_1)\leftarrow -5+0.1\times[-1+(-5)-(-5)]=-5.1
$$

它不会立刻把 $V(S_1)$ 修改为 $-6$，而是只修正一小部分。这就是 TD Learning “边走边学”的核心思想。

# 总结

整篇文章的逻辑可以压缩成下面这条链路：

```text
MDP：描述智能体如何与环境交互
  ↓
Return：计算一条轨迹的累计奖励
  ↓
Value Function：衡量状态或动作的好坏
  ↓
Bellman Equation：建立当前价值和下一状态价值的递归关系
  ↓
Monte Carlo / Dynamic Programming / TD：使用不同信息估计价值
  ↓
Q-Learning / SARSA / DQN：进一步学习动作价值
```

其中，TD Learning 的状态价值更新公式还可以推广到动作价值函数 $Q(s,a)$。下一篇文章会在这个基础上介绍 Q-Learning、SARSA 和 DQN。
